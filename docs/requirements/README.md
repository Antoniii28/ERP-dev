# Requisitos funcionales base

## Objetivo

Dejar preparado el monorepo base para un ERP con módulos modulares y preparación para crecimiento.

## Requisitos cubiertos

- Estructura monorepo con apps y packages.
- API REST base con `/api/v1/health`.
- Configuración centralizada de entorno.
- Preparación de MongoDB Atlas.
- Frontend web base.
- Frontend móvil base.
- Shared packages con tipos útiles.
- Documentación inicial y README principal.
